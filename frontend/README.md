# StudyFlow AI — Desktop Application

The native desktop client for StudyFlow AI built with **Electron**, **Node.js**, **SQLite**, and modern web standards.

---

## Features

- **Local-First**: Complete study planning, tasks, notes, and Pomodoro timers work seamlessly without internet.
- **Embedded Database**: Fast, reliable embedded storage powered by SQLite and encrypted safe storage.
- **Floating Mini Widget**: Always-on-top draggable widget for active task tracking and study streaks.
- **Multi-Account Support**: Isolated data storage per user profile.
- **Jass AI Integration**: Direct assistance for study schedules, syllabus breakdown, and coach chat.

---

## Development

```bash
# Install dependencies
npm install

# Start development application
npm start

# Run automated test suites
npm test

# Build unpacked Windows directory
npm run build:dir

# Package installer (.exe)
npm run build
```
