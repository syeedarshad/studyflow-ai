# Security Policy

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of StudyFlow AI seriously. If you discover a security vulnerability, please do NOT create a public issue on GitHub.

Instead, please report vulnerabilities privately:

1. Use **GitHub Private Vulnerability Reporting** directly on the repository:
   - Navigate to the **Security** tab of the repository (`https://github.com/syeedarshad/studyflow-ai/security`).
   - Click **Report a vulnerability** to open an advisory.

2. Alternatively, reach out directly to the repository maintainer through GitHub [@syeedarshad](https://github.com/syeedarshad).

Please include:
- A description of the issue and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
- Any suggested fixes or mitigations.

We will review your submission promptly and work with you to release a patch.
