# StudyFlow AI — Media & Demo Asset Guide

This directory contains visual assets and screen recordings used in the repository documentation and GitHub README.

---

## Recommended GIF Assets for README

When recording animations to showcase StudyFlow AI workflows, please follow these guidelines to ensure recordings are crisp, lightweight (<5 MB each), and smooth on GitHub:

### 1. `studyflow-overview.gif`
- **Focus**: Quick tour of the workspace.
- **Flow**: Main Dashboard overview → navigating through Tasks and Goals → opening the floating mini-widget.
- **Target Duration**: 6–10 seconds.
- **Resolution**: 1280×720 or 1600×900 (scaled for web).

### 2. `jass-ai-planning.gif`
- **Focus**: AI study plan generation.
- **Flow**: Entering a course goal or syllabus topic → clicking Generate Plan → reviewing estimated session breakdowns and approving the schedule.
- **Target Duration**: 6–10 seconds.

### 3. `smart-scheduling.gif`
- **Focus**: Timeblocking and calendar integration.
- **Flow**: Viewing the weekly schedule grid → placing or adjusting a study session block without conflicts.
- **Target Duration**: 5–8 seconds.

### 4. `focus-session.gif`
- **Focus**: Deep work and Pomodoro timer.
- **Flow**: Launching Focus Mode → starting the timer with ambient background audio → earning XP on completion.
- **Target Duration**: 5–8 seconds.

---

## Optimization Tips
- Record with tools like **ScreenToGif**, **Gifski**, or **Kap**.
- Keep framerate at **24–30 fps** to balance fluidity and file size.
- Export with lossy compression or color palette reduction to keep files under **4 MB** for fast GitHub page loads.
