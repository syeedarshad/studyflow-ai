# StudyFlow AI — Web Landing Page

The official marketing website and product showcase for StudyFlow AI, built with **React 18**, **TypeScript**, **Vite**, and **Framer Motion**.

---

## Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Bundler**: Vite
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Styling**: Vanilla CSS Design System with dark mode aesthetic

---

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
